# Kräftskiva – Seating Chart

A visual seating chart app for your crayfish party (or any event). Add guests with photos, arrange tables, and zoom in to assign seats.

## Features

- **Guest photos** – Upload a picture for each guest
- **Multiple tables** – Add tables with configurable seat counts
- **Overview layout** – Drag tables around the room view
- **Zoom into tables** – Click a table to open a detailed view with scroll-to-zoom and pan
- **Seat assignment** – Select a guest, then click an empty seat (or click a seated guest to unassign)
- **Auto-save** – Everything persists in your browser's local storage

## Getting started

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## How to use

1. Click **+ Add** in the guest panel to add people with photos
2. Click **+ Add Table** to create new tables
3. Drag tables on the overview to arrange your layout
4. Click a table to zoom in — use scroll wheel or +/- buttons to zoom further
5. Select an unassigned guest from the sidebar, then click an empty seat to place them
